# Graficación

En este repositorio se encuentran los proyectos plantilla que se utilizan en la materia de Graficación. 

## Archivos

- *plantilla2D_v1_11_13.zip*. Este archivo compreso contiene la versión 1.11.13 de la biblioteca P5.js. Las carpetas y archivos están organizados para facilitar su despliegue como sitio Web. Esta versión fue generada utilizando como base la descarga disponible en: https://v1.p5js.org/download/

## Recomendaciones
1. Descargar la plantilla y descomprimirla en una carpeta de su preferencia.
2. Instalar Visual Studio Code (https://code.visualstudio.com/). Asegurarse de marcar las opciones para abrir carpeta y archivos desde el menú contextual.
3. Instalar la extensión `Live Server` dentro de Visual Studio Code
